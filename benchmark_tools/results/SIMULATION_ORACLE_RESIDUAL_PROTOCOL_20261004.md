# Generating-Root Residual History Trace

## Scope

The preceding generating-root oracle and independent count readback are fixed.
Screen all 70 cells / 10,125 candidates and select every candidate with a
within-candidate false positive or false negative in that arm. Existing results
identify 20 candidates (eight oracle-eligible, twelve unambiguous bypasses).
This is a complete **post hoc mechanism diagnostic**, not a prospective accuracy
test or a claim that the cohort was chosen without inspecting outcomes. Freeze
this plan and worker/tests before executing the new event-history analysis.

No native search, tree inference, matched timing, default change or outcome-based
candidate subset is requested. Keep all previously reported cross-candidate
losses and oracle eligibility unchanged. Bypasses remain bypass predictions;
their generating trees are consulted only to explain event correspondence.

## Analysis

- Pin the detailed oracle and readback, native admission, preparation and frozen
  reconciliation source. Bind candidate membership, FASTA ownership, original
  truth, species trees, native constraint policy and satellite sidecars.
- Read original simulator event tables and reconciled XML for every selected
  ancestor. Require exact event/child correspondence, complete parent-family
  leaves and original truth-pair reproduction. Induce the same generating tree
  used by the oracle; do not reroot it.
- Trace **every** cross-species pair in each selected candidate, not just errors.
  Record its original history LCA/event, frozen induced reconciliation call,
  original parent and retained candidate species overlap, raw pair call, root
  group, post-constraint group, and unsupported satellite event attribution.
- Require each induced pair ancestor's complete gene clade and species overlap
  to agree with its original history ancestor restricted to candidate genes.
  Reproduce the retained oracle
  TP/FP/FN exactly before interpreting an error class.
- Classify false negatives as raw pair-rule exclusion, root-partition filtering,
  or unsupported satellite constraint filtering. Classify false positives as
  bypass calls at a true duplication or positive-paralogy calls at a true
  duplication without retained species overlap. Unexpected semantics fail
  explicitly; do not modify labels or silently drop a candidate to finish.
- Retain true positives/true negatives, parent-versus-candidate overlap and all
  constraint evidence. These distinguish unavailable ancestral signal from an
  observed filtering decision; they do not prove how to change real-data defaults.
- Recheck selected input identities before output. Generate tables from the
  machine-readable report. Independently read back row arithmetic, whole-cohort
  selection, original event ancestors and original oracle count identities.

## Reporting

Use finite-panel counts, no sampling CI or significance/superiority claim.
Simulation histories contain privileged information. Frozen-rule reuse is not
independent validation of the reconciliation algorithm. Preserve negative and
unexplained outcomes, and report failed executions without retrying an unchanged
scientific computation. This adds mechanism evidence to goal4.4; all remaining
publication requirements, primary QfO/OrthoBench priorities and shared-host timing
limitations remain intact. Focused commits/pushes precede actual analysis and
follow validated reporting. Large local pair reports remain pinned, not deposited.
