# Native SwissTrees Reconciliation Localization

This retrospective follow-up uses the complete2,023 changed-pair ledger from
the independently checked native P0/C0 comparison. All families and both TP
and FP removals are included. Do not restrict the trace to PSEN/RPS/APP or
describe the previously observed score differences as a new confirmatory test.
Do not tune the method or reinterpret the failed R1 inference timing.

Use `trace_native_qfo_swiss_reconciliation.py` in the original Python3.10
runtime, sanitized environment and one-thread numerical libraries. First
replay the independent stdlib/SQLite pair-transition readback. Bind both
actual original scientific admissions, conversion identities, terminal/
scientific-recovery reviews and native output inventories. Only inspect
completed indices6/7, not unfinished index8 outputs.

R0's admitted clustered-file hash must equal the admitted R1 manifest's
recorded input-cluster hash. Stream R1's admitted RootHOG records to reconstruct
each original source family's sorted genes, in canonical family order. Hash
the complete reconstructed input and require that same R0 checksum. Check
input-gene and RootHOG totals against original native output validation.
Match every changed-pair accession injectively to its actual native gene,
source family and final RootHOG. This verifies matching candidate-group bytes,
not identical search-hit histories or a total-HMM ablation.

The original output validator did not inventory
`orthohmm_reconciliation_nodes.tsv`. Record its newly observed current-byte
digest explicitly; do not call it an originally admitted annotation file or
retroactive execution proof. Read all structured rows, retaining complete
annotation trees only for source families touched by changed pairs. Check
unique node IDs, one root, parents, connectivity/acyclicity, exact descendant
gene sets, species unions, child-species overlap, mapping-conflict flags and
the configured positive-paralogy pair-event rule. The serialized confidence
and support remain observed model annotations, not calibrated probabilities.

Walk parent pointers to each changed pair's lowest common ancestor. Verify
the pair was in a shared candidate family and is actually absent from the
admitted native prediction file. Check the whole native row count. Record
whether final RootHOGs differ, the exact LCA node, event, overlap, confidence,
mapping flag and serialized support in a complete deterministic ledger.
Every removed pair must have a duplication pair-event with positive child
species overlap under the configured rule; otherwise preserve the refusal
and investigate rather than forcing an explanation.

Check all direct evidence before and after analysis; retain partial outputs
or failures and require fresh result paths. No alignment, tree inference,
reconciliation, search or endpoint scoring is executed. Diagnostic wall/RSS
values are shared-host postprocessing observations, with unknown potentially
tool-dependent contention, not native inference timing or isolated estimates.

This can establish the software path for exclusions and distinguish final
group splitting from within-group pair resolution. It does not establish true
duplication history, inferred-tree correctness, biological causation or
independent generalization. Direct search/candidate/error strata, tree-error
analyses, missing native cells and wider uncertainty remain separate work.

Require every pair's independently found LCA node/event/descendant count to
