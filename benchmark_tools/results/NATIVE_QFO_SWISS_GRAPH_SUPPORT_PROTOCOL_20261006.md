# Native SwissTrees Graph-Support Trace

Post-hoc diagnostic, defined before inspecting selected graph outcomes.
Trace the complete 2,023 changed P0/C0/R0-versus-R1 SwissTrees pairs, not
representative successes. Initial HMM search remains on in both cells;
this is not a total-HMM ablation or a sensitivity-matched non-HMM comparator.
Preserve frozen method/defaults/endpoints, accuracy admissions and failed timing.

Reuse the actual significant-search report and independent readback, original
localized pair ledger, admitted native output inventories, metrics and R0
candidate partition. Require exact identities and source/scope bindings.
Require the candidate hash to match the already reconstructed R1 input.
Check the original native plan/baseline and relevant frozen source identities,
not a fresh transitive admission of all helpers or proteome bytes.

The final `orthohmm_edges.txt` files were not inventoried by the original
output validator. Pin them as newly observed current-byte evidence, check
before and after scanning and explicitly deny retroactive original graph
admission or continuous integrity. Scan each complete file, requiring finite
weights, valid known distinct endpoints, canonical sorted unique undirected
pairs and the admitted metric's exact final network-edge row count.
Do not assume identical final graph bytes or positive weights; report those
observations rather than using them as inclusion criteria.

Extract every original candidate family containing changed endpoints and its
complete native members. Keep within-family induced graph edges, including
same-species nodes and non-reference genes. For every changed pair and cell,
report its direct graph record or absence, unweighted within-family shortest
path and complete path witness, or disconnection. A missing induced path
does not establish global graph disconnection. A present path establishes
observed connectivity, not causal clustering recruitment, sequence-search
correctness or biological orthology. Direct edges must have an actual stored
significant hit of the same weight; retain directional evidence from the
already checked search report, without scanning the hit arrays again.

Cross-tabulate prior TP/FP, no/one/both-direction significant search support,
and direct-edge/indirect-path/disconnected induced graph status for both
native views, including zero cells. Report any graph/view differences rather
than forcing equality. Save complete case and induced-edge data, actual row
offsets, member inventories and exact machine-readable tables.

Primary traversal uses breadth-first search with deterministic lexical neighbors.
Independent readback uses a separate CSV graph scan and per-family NumPy
Floyd-Warshall distances, not primary scanner/path imports. Verify every actual
induced edge, all cases/direct records, all distances/path witnesses, counts,
cross-tabs and table bytes against source reports. Bound matrix size before
allocation; do not replay inference, Leiden, refinement, tree/scoring or
bootstrap. Focused arithmetic, malformed graph/binding/path and actual-result
tests must preserve failures. Synthetic fixtures are not native admission.

Original index8 job and its dependent stages remain untouched; never read
unfinished outputs or release its successor early. Shared-host diagnostic
resources have unknown potentially tool-dependent contention, not corrected
or isolated timing. No unrelated jobs/services or frozen files may change.
This diagnostic strengthens the error-stage analysis only; it does not finish
the full publication goal or repair failed R1 inference timing.
