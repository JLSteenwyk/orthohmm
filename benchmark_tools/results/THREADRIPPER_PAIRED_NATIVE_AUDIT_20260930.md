# Paired Native Receipt And Output Audit

The [new audit component](../audit_threadripper_overhead.py) checks the raw/output
portion of the prospective 27-pair/54-task engineering design. It does not submit
work or complete full runtime, environmental, scheduler-step or timing admission.
The local quiet window remains deferred. Do not repeat successful fixtures 22380
or 22381 to test this new component or run scientific inference merely to populate
its table.

## Checks And Scope

- Validate all frozen method/size/repeat identities and full native run objects
  against their pinned parent after the prescribed fresh-path relocation.
- Require bound, ordered, unique one-attempt history; no skipped identity,
  repeated job, selective retry or omitted prescribed task.
- Retain all 54 task states, including unrun, scheduler failure, native failure,
  invalid evidence and a nonterminal record requiring a fresh live check.
- Do not inspect native outputs from non-successful scheduler allocations.
  Bind recorded terminal controller resources, command, cwd and time limit.
- Replay the actual boundary or periodic raw collector with expected native
  command and external launcher/worker bindings; require the periodic v5 schema.
- Use existing native format, input-order, species/sequence mapping and complete
  universe checks before computing canonical orthogroup/root-HOG/native-pair
  identities. Reject indirect output trees. Formatting equality is not biology.
- Retain resource brackets and raw flags; check native bracket order and common
  boot identity. Stop progression after native invalidity or pair output mismatch.
- Recheck evidence hashes and absent unrun paths after auditing. A changed
  inventory is incomplete evidence, not a stable empty panel.

The component reuses existing readers and validators. It is not an independent
implementation of every arithmetic formula or a replacement for a complete
source/runtime/loaded-dependency audit. Controller readback is not terminal
native-step accounting. A nonterminal saved record must be refreshed from the
original job; this component neither polls it nor treats it as a terminated job.

## Numerical Comparison

Report the signed `periodic / boundary - 1` ratio, including negative values.
Threshold comparisons use exact integer-native-clock fractions: <=1/10 for each
pair and <=1/20 for the median of all three consistent pairs per method/size.
This implements the existing decimal engineering limits without a floating-point
tolerance or a post-outcome amendment. A one-nanosecond excess is not rounded
into a pass. Displayed ratios are floats; decisions use exact fractions.

An incomplete pair has no ratio, and an incomplete cell has no median. A panel
issue prevents a complete-panel numerical decision. Even complete numerical
success leaves `engineering_budget_passed=None` and runtime/environment/timing
admission false. No cache eviction, subtraction, timing correction, causal
slowdown claim, execution permit or publication readiness follows.
