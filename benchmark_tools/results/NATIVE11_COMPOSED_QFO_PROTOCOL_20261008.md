The separate conversion, execution and admission modules consume the truthful
new composed review type. All original reviewers, consumers and scientific
kernels remain unchanged. This is prospective postprocessing, not another
inference attempt, new benchmark baseline or ordinary-schema translation.

## Prerequisite

Producer24034 must be successfully terminal and its actual complete review
must pass independent readback and the explicit composed binding. Retain original
failures23986/24033 and completed standalone semantic producer24031. Do not
execute conversion from a partial runtime component or a running producer.

`prepare_native11_composed_qfo_pairs.py` with original request, actual composed
review and exact prospective source digests. The fresh namespace is
`benchmarks/results/native11_composed_qfo_pairs_v1`.

groups at `native/orthohmm_working_res/orthohmm_edges_clustered.txt` and the

Reject any missing accession, noninjective normalization or mapping loss.
Require expected/materialized/retained/coverage counts and bytes to agree.
Singleton/no-relation inputs remain in the full coverage denominator.

## Assessment And Admission

After successful conversion and independent readback, one8CPU32GiB26h/no-requeue
assessment runs the unchanged command kernel, event2020, six endpoints
`GO EC VGNC SwissTrees TreeFam-A FAS`, original reference environment and FAS
protocol. No Nextflow `-resume`, endpoint changes or resampling. Distinct paths:
`benchmarks/results/native11_composed_qfo_assessment_v1`,
`qfo_benchmark/w/cn11`, `qfo_benchmark/scoring/composed_native11_v1`.
The participant remains `ohmm_qfo_full_native_p1_c1_r0`.

After successful assessment, one2CPU32GiB6h/no-requeue independent admission
uses the unchanged completion, endpoint, trace and FAS sample validators.
The namespace is `benchmarks/results/native11_composed_qfo_admission_v1`.
Rebuild the expected execution spec and recheck source, all files and complete
output inventory. Require all six original endpoint structures, participant,
completed trace tasks and FAS arithmetic/pair-population checks. A successful
process alone is not scoring admission.

## Retention And Timing

For each actual job, inspect existing handles/destinations, submit held once,
retain/check owned identity/command/cwd/resource/comment/source bindings,
recheck safe capacity and release once. No quiet-host requirement or unrelated
workload changes. Retain failures without automatic repeats, missing-score
imputation or benchmark relabeling. Conversion/scoring/admission intervals
remain separate from measured native inference.

VGNC/SwissTrees/TreeFam-A are F1; GO/EC similarity and FAS are not F1.
The six-metric mean stays a project-defined secondary summary. Family-level
uncertainty and independent biological validation are not supplied by scoring
admission. Shared-host timing limitations remain explicit. This route never
authorizes native12 history-dependent execution or publication readiness.

## Verification Scope

Real small-fixture group conversion, original endpoint/trace/FAS validators,
failure handling and new-type rejection are tested. Native and scheduler
contexts in these fixtures are stubs. Synthetic endpoint values are not
production benchmark results. Production source-only preparation does not
establish actual scoring, full-review success or scientific superiority.
