## Remaining Boundary

This inspection covers recognized COPY/ADD-to-/benchmark layers on selected
single images or linux/amd64 platforms. It does not search every other image
layer, architecture, registry, deleted image, differently named/encoded file or
archive embedded in a context member. Filename/header absence is not global
source unavailability. Remaining searches need concrete new leads, not repeated
downloads of these 40 contexts.

Complete original TreeFam-A release-7 trees and `treefam2reference.txt` remain
unrecovered. No reconstruction against pooled reference pairs or family-level
uncertainty can be admitted from this search. Controlled Threadripper timing
is still deferred, and no current readiness recipe is approved by these helper
changes. The publication goal remains active, not complete or blocked.
