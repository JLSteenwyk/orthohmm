## Copied Main-Result Commands

The four commands below use the existing rc6 `statistics/` paths. This turn
compared every one of its 24 statistics payload records (path, bytes, SHA256,
mode) with the already executed rc2 index; all match. The three nested archives
and two external anchors also match. The original
[four-route execution](results/PUBLICATION_PACKAGE_RC2_RESULT_20261004.md)
is reused, not rerun or claimed as a fresh rc6 scientific execution.

After trusted restoration, set `PACKAGE` to the restored root, `PYTHON` to a
separately provisioned Python with NumPy 2.2.6, and `FRESH` to a writable
directory outside the immutable package. Every named output must be absent.
Set OpenBLAS/OMP/MKL thread limits to one; these are arithmetic replays, not
timing benchmarks or new native-score admissions.

```sh
"$PYTHON" -I -B "$PACKAGE/statistics/benchmark_tools/check_ob_complete_uncertainty.py" \
  --portable "$PACKAGE/statistics/benchmark_tools/results/ob_complete_portable_statistics_20260928.json" \
  --sha256 cdb30ff987100843f3127a39a75eb3649123a136229b8b41e6ed156209aff30e \
  --output "$FRESH/ob-comparison"
"$PYTHON" -I -B "$PACKAGE/statistics/benchmark_tools/reproduce_corrected_swiss_comparison.py" \
  --results "$PACKAGE/statistics/benchmark_tools/results/qfo_recovered_swiss_uncertainty_22178.json" \

  --retained-counts-only --output "$FRESH/swiss-comparison.json"
```

## Availability And Limits

Project code and documented workflows are in the authorized Git repository;
large raw data, installed tools, local execution components and the rc6 archive
are not newly committed. Exact acquisition/notice routes are in the
[reproduction guide](PUBLICATION_REPRODUCTION.md) and
[retained rights inventory](results/PUBLICATION_DATA_RIGHTS_20260918.md).
OrthoBench/YGOB raw data and scorer content remain acquisition-only for new
packaging. Local retention or a project MIT license is not clearance for
upstream data, binaries, containers or an arbitrary selected release.
Original TreeFam trees/mapping remain unrecovered within the recorded search
scope, without implying global unavailability. No contacts are required.

Scientific validation is bounded: primary datasets are development-exposed,
YGOB is novel-taxon rather than family-disjoint confirmation, annotation/tree
descriptors are not complete biological truth, and fresh-native failures stay
missing. No general OrthoFinder advantage for OrthoHMM is established.
Supported inferential comparisons retain their original units, endpoints,
multiplicity and exchangeability limitations.

Timing measurements were collected on a shared Threadripper while other
analyses were running. Competition for CPU, memory bandwidth and I/O may have
affected elapsed times, with an unknown and potentially tool-dependent impact.
These are observed shared-host timings, not estimates of isolated performance.

Public release/upload, archival DOI and journal submission have not occurred.
Journal layout, repository/data-deposition destination and any required
redistribution review are external delivery steps, not completed operations.
The local versioned package, Git supplements and actual checks must not be
represented as public deposition, unrestricted generalization or hermetic
all-tool study restoration. Current goal completion is assessed separately,
requirement by requirement, not inferred from this index.
