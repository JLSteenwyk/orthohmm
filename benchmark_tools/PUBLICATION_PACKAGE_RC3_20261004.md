No scientific package is required. Set `PACKAGE` to the restored directory and
choose an absent output path outside it:

```sh
python3 -I -S -B "$PACKAGE/evidence/replay_simulation_mechanisms.py" \
  --inputs "$PACKAGE/evidence" --output /fresh/mechanism-replay
```
